Build :
-Openstint decoder with rtlsdr V4 installed on raspberry pi
-DS3231 RTC + CR2032 (optional)
-LCD 16x2 I2C (optional)
-Loop according to Openstint recommandations

How to upload software on a new Raspberry :
-Connect to Raspberry with ssh
-Copy folder using FileZilla or other
-In the files folder, run sudo bash install.sh

Admin password is defined in admin.js
WiFi parameters are defined in install.sh
